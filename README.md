# English Patterns

App de estudo de inglês com padrões e quiz.

## Como rodar localmente

```bash
npm install
npm run dev
```

Abre em http://localhost:3000

## Deploy na Vercel

1. Sobe o projeto no GitHub
2. Entra em vercel.com → New Project
3. Conecta o repositório
4. Clica em Deploy

Pronto. Sem configuração extra.

## Funcionalidades

- 18 categorias de gramática
- 180 frases com tradução
- Quiz por categoria (acertei/errei)
- Busca em todas as frases
- Score acumulado de quiz
